# STP Team

Use `1ststepai/swingtradepros` GitHub issue `#338` and open `stp-queue` issues as the shared memory. Chat snippets and local caches are context only.

1. Read `#338`, then list `stp-queue + ready` and `stp-queue + claimed` issues.
2. Re-read the selected issue and recent comments immediately before acting.
3. Select one eligible task only: priority first, then oldest within the same priority. Respect dependencies and overlapping claims.
4. Use the matching role skill. Stay single-agent unless the user explicitly requests delegation.
5. Preserve lifecycle evidence: lease/claim, result, final label, and a short status on `#338` when the queue protocol requires it.

If no issue is ready, report the exact blocker and the single next action. Do not silently promote blocked work.
